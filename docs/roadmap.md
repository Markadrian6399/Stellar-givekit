# Product Roadmap

## Phase 1 - MVP
- Campaign CRUD
- Soroban donation contract scaffolding
- Donation verification endpoint
- Campaign list and details UI
- Basic analytics overview

## Phase 2 - Trust and transparency
- Campaign publish workflow
- Wallet-based authentication
- Milestone tracking
- Donor badges
- Event processor for insights

## Phase 3 - Growth
- Recurring donations
- Social sharing and referral support
- Leaderboards and quests
- Creator admin tools
- Better observability and alerts

## Phase 4 - Ecosystem integrations
- SEP support where needed
- Federation support
- NGO onboarding templates
- Multi-asset support
